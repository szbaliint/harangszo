# Harangszó Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the map, parish portal and admin one calm, phone-first, installable app look (tone A, EB Garamond + Source Sans 3).

**Architecture:** A shared design system in `styles.css` (tokens + `ui-` prefixed components) lands first; each page then moves onto it in its own task and deletes its old rules. The week board and time editor become one shared browser script, `schedule-editor.js`, used by the parish portal and admin. The public map becomes a PWA (manifest, icons, `sw.js`).

**Tech Stack:** Vanilla JS + CSS, no build step; GitHub Pages; Supabase (supabase-js from CDN on portal/admin, plain `fetch` on the map); tests with `node --test` + the pre-installed Playwright.

**Spec:** `docs/superpowers/specs/2026-11-09-redesign-design.md` (mockups in `docs/superpowers/specs/2026-11-09-redesign-mockups/`).

## Global Constraints

- No build step; no new runtime dependencies. Tests use only `node:test` and the globally installed `playwright`.
- No change to the data model, RPCs (`public_data`, `save_church`, …), imports or permissions. Saving stays in each page via `save_church`.
- UI text Hungarian; code, comments and commit messages English.
- Fonts: **EB Garamond** (600/700) for headings and church names, **Source Sans 3** (400/600/700) for everything else, times with `font-variant-numeric: tabular-nums`. **No monospace, no IBM Plex, no Spectral** anywhere.
- Tone A tokens exactly as the spec's table (light and dark). Existing token names (`--accent`, `--penance`, `--gold`, `--open`, `--closed`, `--ink-2`, `--ink-3`, `--glass`, `--on-accent`, `--mk-none-bg`, `--mk-none-ink`, `--border`, `--land`) are kept; `pal()` in `app.js` reads them.
- Text and tag colours reach WCAG AA (4.5:1) on their backgrounds in both modes.
- Tap targets ≥ 44px; easing `cubic-bezier(.2,.8,.2,1)`, 180–280ms; nothing animates under `prefers-reduced-motion: reduce`.
- New shared components use the `ui-` class prefix so they never collide with old page rules (`.chip`, `.card`, `.tag`, `.seg`, `.field` exist on pages today).
- Every `localStorage` read/write is in try/catch; pages work with it empty or throwing.
- Every new deployable file is added to the `cp` line in `.github/workflows/pages.yml`.
- Never commit keys; `config.js` keeps its `__PLACEHOLDER__`s.

## Review Focus

1. A very long church name ("Budapest-Belvárosi Nagyboldogasszony Főplébánia-templom (Belvárosi templom)") must wrap in the detail header, list card, Legközelebb card and admin header without overflow or covering buttons. → test in Tasks 4 and 8.
2. A church with no schedule at all must show a calm empty state (today's text "Ehhez a templomhoz még nincs feltöltött időpont…") instead of an empty hero card or empty folds. → test in Task 4.
3. `localStorage` throwing (private mode, blocked storage): map, Mentett and the data cache must not break the page. → test in Task 3.
4. A crowded day (8+ times on Sunday) on a 360px-wide phone: tiles wrap inside the day card, the ＋ tile stays reachable. → test in Task 5.
5. First visit while offline (no service-worker cache, no data cache): the map shows the offline note and the empty list explains why, no endless spinner. → test in Task 9.
